# Python Course — edutube

ক্লাস ৬–১২ এর শিক্ষার্থীদের জন্য গেমের মতো করে পাইথন শেখার ওয়েবসাইট।
EATL Innovation Hub Limited ও edutube এর উদ্যোগ।

## কীভাবে চালাবে

- **সবচেয়ে সহজ:** `index.html` ফাইলে ডাবল-ক্লিক করো। ব্রাউজারে খুলে যাবে।
- **ওয়েবসাইটে তুলতে:** পুরো ফোল্ডারটা যেকোনো হোস্টিংয়ে (cPanel, Netlify, GitHub Pages) আপলোড করো।
  কোনো সার্ভার-কোড বা ডেটাবেস লাগে না।
- ফন্ট (Tiro Bangla) Google Fonts থেকে আসে, তাই প্রথমবার ইন্টারনেট লাগে।

## ফোল্ডারের গঠন

```
python-course/
├── index.html              ← মূল পেজ (নতুন পাঠের <script> লাইন এখানে যোগ হয়)
├── css/style.css           ← ডিজাইন, রং, ফন্ট
├── js/
│   ├── pylite.js           ← ব্রাউজারে পাইথন চালানোর ইঞ্জিন
│   ├── course-data.js      ← ট্র্যাক → মডিউল → পাঠের তালিকা ও নাম
│   ├── core.js             ← প্ল্যাটফর্ম (ম্যাপ, XP, ব্যাজ, সাউন্ড, কুইজ...)
│   └── games.js            ← ৫ ধরনের গেম
├── lessons/
│   ├── lesson-b-1-1.js     ← পাঠ ১.১ পাইথন পরিচিতি (সম্পূর্ণ)
│   └── _template.js        ← নতুন পাঠ বানানোর টেমপ্লেট
├── assets/                 ← লোগো
└── videos/                 ← রেকর্ড করা ভিডিও রাখার জায়গা
```

## নতুন পাঠ যোগ করার ৪টি ধাপ

1. `lessons/_template.js` কপি করে নতুন নাম দাও, যেমন `lessons/lesson-b-1-2.js`
2. ফাইলের ভেতরে `key: 'b-1.2'` লেখো।
   - key = ট্র্যাক prefix + `-` + পাঠের id (`js/course-data.js` এ যেমন আছে)
   - Beginner = `b`, Intermediate = `i`, Advanced = `a`
   - উদাহরণ: Beginner এর পাঠ 1.3 → `b-1.3`, বস প্রজেক্ট → `b-boss1`
3. ভিডিও, স্টাডি ম্যাটেরিয়াল, মিশন, কুইজ, সারসংক্ষেপ লেখো।
4. `index.html` এ এই লাইন যোগ করো (অন্য lesson লাইনের নিচে):
   ```html
   <script src="lessons/lesson-b-1-2.js"></script>
   ```

ব্যস! ম্যাপে পাঠটা নিজে থেকেই চালু হয়ে যাবে। আগের পাঠ শেষ হলে শিক্ষার্থী এটা খুলতে পারবে।

> **পরীক্ষা করার সময়:** লকড পাঠও সরাসরি খোলা যায় এই ঠিকানায়:
> `index.html#lesson-b-1-2` (key-এর `.` এর জায়গায় `-`)

## রেকর্ড করা ভিডিও যোগ করা

ভিডিওটা `videos/` ফোল্ডারে রাখো (mp4 সবচেয়ে ভালো), তারপর পাঠের ফাইলে:

```js
video: { title: '...', src: 'videos/lesson-b-1-2.mp4', poster: 'videos/lesson-b-1-2.jpg', xp: 20 }
```

`src` দিলে অ্যানিমেটেড scenes এর বদলে আসল ভিডিও চলবে। ভিডিও শেষ হলে XP পাবে।

## ৫ ধরনের গেম (mission type)

| type | কী করে | মূল ঘর |
|---|---|---|
| `sequence` | ধাপগুলো সঠিক ক্রমে সাজাও | `rounds: [{title, steps:[[icon, লেখা]], result, hint}]` |
| `predict` | কোডের আউটপুট অনুমান | `rounds: [{code, opts:[সঠিক, ভুল, ভুল], ex}]` |
| `match` | জিনিস সঠিক ঘরে মেলাও | `bins: [[id, icon, রং, নাম]]`, `items: [[লেখা, binId]]` |
| `bug` | বাগ থাকা লাইন খোঁজো | `rounds: [{lines, bug (০ থেকে), fix, why}]` |
| `fix` | ভাঙা কোড সারাও (+চ্যালেঞ্জ) | `broken, fixed, expect, challenge?` |

প্রতিটা mission এ `badge: {id, e, n, d}` দিলে শেষ করলে ব্যাজ পাবে (id সব পাঠে আলাদা হতে হবে)।

## কুইজ

```js
quiz: [ { q: 'প্রশ্ন', o: ['সঠিক উত্তর', 'ভুল ১', 'ভুল ২', 'ভুল ৩'], ex: 'ব্যাখ্যা', code: 'ঐচ্ছিক কোড' } ]
```

`o` এর প্রথমটা সবসময় সঠিক। দেখানোর সময় অপশনগুলো এলোমেলো হয়ে যায়।

## পাইথন ইঞ্জিন সম্পর্কে

`js/pylite.js` হলো ব্রাউজারে চলা ছোট পাইথন। এটা মডিউল ১ এর সব কিছু চালাতে পারে:
print, input, variable, হিসাব (+ − * / // % **), string, f-string,
int/float/str/bool/type/len/round, string method। এরর এলে আসল পাইথনের মেসেজ আর বাংলা ব্যাখ্যা দেখায়।

`if`, `for`, `while`, `def` এখনো চলে না। মডিউল ৩–৪ এর আগে পূর্ণ পাইথন লাগবে।
তখন নিজের সার্ভারে Pyodide (https://pyodide.org) যোগ করা যাবে।

## অন্যান্য

- **সাউন্ড:** সব শব্দ কোড দিয়ে তৈরি (Web Audio), কোনো অডিও ফাইল লাগে না।
  শব্দ বদলাতে `js/core.js` এর `Sound` অংশ দেখো। হেডারের 🔊 বাটনে বন্ধ/চালু হয়।
- **অগ্রগতি:** শিক্ষার্থীর XP, ব্যাজ আর অগ্রগতি তার নিজের ব্রাউজারে (localStorage) সেভ থাকে।
- **লেভেল ও সাধারণ ব্যাজ:** `js/course-data.js` এর নিচে।
- **রং ও ফন্ট:** `css/style.css` এর একদম উপরে `:root` অংশে।
